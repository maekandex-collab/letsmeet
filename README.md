# LetsMeet

A modern mobile-first dating app built with Next.js 14 and Tailwind CSS.

## Features

- Onboarding flow with profile setup
- Country & state location picker
- Match discovery
- Real-time messaging
- Notifications

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
